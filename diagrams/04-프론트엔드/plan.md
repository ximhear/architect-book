### [01-channel-mapping.excalidraw] 채널 구성 메타포 — 같은 사용자, 5가지 얼굴

- **위치**: 본문 1절 채널 구성 표 다음
- **목적**: iOS / Android / 모바일웹 / PC웹 / 셀러어드민 이 같은 사용자에게 다른 얼굴로 보이는 것을 메타포로
- **표현**:
  - 가운데 사람 (사용자) 1명
  - 5방향에 5개 화면 (각 디바이스 모형)
  - 각 화면 아래 비중 (%) + 기술 스택 라벨
  - 화살표 — 한 사용자가 채널을 전환하는 흐름 (예: 카카오톡 링크 → 모바일웹 → 앱 설치)
- **메타포**: "한 사람의 5얼굴"
- **우선순위**: 보통

### [02-live-screen-composition.excalidraw] 라이브 화면 합성 — 다층 구조

- **위치**: 본문 9.2 라이브커머스 절
- **목적**: 라이브 화면이 영상 / 채팅 / 좋아요·구매 / 상품 카드 4개 레이어로 합성됨을 시각화
- **표현**:
  - 모바일 화면 frame
  - 4개 레이어를 분해해 위에서 아래로 (영상 / 채팅 fanout / 인터랙션 / 상품 정보)
  - 각 레이어의 데이터 출처 — HLS CDN / WebSocket / 인터랙션 batch / 상품 API
  - 우측에 "단일 노드 5천 시청자 한계" 콜아웃
- **메타포**: "케이크 단면도"
- **우선순위**: 높음 (라이브가 본 책 케이스의 차별 영역)
