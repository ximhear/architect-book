# 대한민국 서비스 아키텍트 입문서

> 클라우드부터 프론트엔드까지, 한 명의 아키텍트가 대한민국 환경에서 동작하는 실서비스를 처음부터 끝까지 설계하기 위한 입문서.

**상태**: 1차 드래프트 + 베타 리뷰 완료 (Phase 5 진행 중)
**판본**: 2026년 상반기 기준 / **시점 면책**: 빠르게 변하는 도구·법규는 본문에 "확인 필요" 명시
**라이선스**: 산문 **[CC BY-NC-SA 4.0](LICENSE)** (저작자표시·비영리·동일조건변경허락) · 코드 예제 **[MIT](code-samples/LICENSE)** ([ADR-0007](adr/0007-라이선스-제안.md))

---

## 이 책은 누구를 위한 책인가

- **시니어 백엔드 / 프론트엔드 개발자** — 한 영역에선 깊지만, 서비스 전체 그림을 그려야 할 때 길이 흐릿한 사람
- **스타트업 CTO · 리드 개발자** — 모든 결정을 혼자 내려야 하는 위치
- **클라우드 / 인프라 엔지니어** — 애플리케이션 영역까지 시야를 넓히려는 사람

전제: 한 가지 이상의 언어로 3년 이상 실무 경험. 기초 문법·HTTP 입문은 다루지 않는다.

## 무엇이 다른가

- **한국 시장 한정** — NCP / KT / NHN, 망분리, ISMS-P, PG / 간편로그인, 한글 UI 가 1차 맥락. AWS-only 책의 번역이 아님.
- **트레이드오프 중심** — "정답 없음, 선택지와 결과". 모든 결정 절에 트레이드오프 박스.
- **케이스 단일 출처** — 가상의 종합 커머스 **원픽 (월 1,000만 MAU)** 위에서 8개 영역을 일관되게 다룸 ([케이스 스터디](manuscript/case-study/README.md)).
- **ADR 기반 의사결정 문화** — 책 자체의 의사결정도 [ADR 9개](adr/) 로 기록.

## 집필 원칙 7가지 (요약)

전체는 [`CLAUDE.md`](CLAUDE.md) 의 "집필 원칙" 절.

1. **한국어 1차** — 기술 용어는 영어 병기 ("관측성(Observability)")
2. **국내 환경 우선** — AWS-only 가 아닌 NCP·KT·NHN·망분리·금융망 함께
3. **트레이드오프 중심** — 정답이 아닌 선택지와 그 결과
4. **다이어그램 우선** — Mermaid C4 / 시퀀스 / 데이터 플로우
5. **ADR 형식** — Context → Decision → Consequences
6. **최신 기술 스택 반영** — 매년 1회 갱신 전제
7. **케이스 단일 출처** — [`case-study/README.md`](manuscript/case-study/README.md) 가 모든 사례의 단일 출처 ([ADR-0008](adr/0008-케이스-단일-출처-원칙.md))

## 베타 리뷰

[베타 리뷰 운영 가이드](review/README.md) 와 [회람 안내](review/reviewer-pack.md) 가 준비되어 있다.

리뷰어로 참여하고 싶다면:

1. [`review/reviewer-pack.md`](review/reviewer-pack.md) 를 먼저 읽고
2. GitHub Issue 의 `[베타 피드백]` 라벨 또는 이메일로 회신
