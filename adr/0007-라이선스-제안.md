# 0007. 라이선스 — CC BY-NC-SA 4.0 (산문) + MIT (코드)

- **Date**: 2026-05-08 (Proposed) / 2026-05-09 (Accepted)
- **Status**: **Accepted**
- **Deciders**: 저자

## Decision

- **산문 / 다이어그램 / ADR / 케이스 스터디 등 모든 콘텐츠**: **CC BY-NC-SA 4.0** (Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International)
- **코드 예제** (`code-samples/`): **MIT** (자유 활용)

LICENSE 파일은 리포지토리 루트 (`/LICENSE` — CC BY-NC-SA 4.0) 와 코드 디렉토리 (`/code-samples/LICENSE` — MIT) 에 분리.

## Context

책의 형태(자체 공개 / 출판사 / 동시 진행)가 아직 미정이다.
일단 GitHub 에 공개하더라도 "저작자 표시", "비영리 한정", "동일 라이선스 전파" 정도의 보호는 두는 것이 안전하다.

코드 예제는 독자가 자유롭게 가져다 쓸 수 있어야 학습 효과가 크므로 별도 라이선스로 분리한다.

## Considered Alternatives

- **All rights reserved**: 가장 보호적이나 학습 콘텐츠의 공유 효과 손해
- **CC BY 4.0 (상업 허용)**: 가장 자유로우나 무단 출판 위험
- **MIT (전체)**: 코드에는 적합하나 산문 콘텐츠에 부적절

## Consequences

### 긍정적
- 학습용·인용·번역은 자유 → 확산 효과
- 상업적 재배포는 차단 → 출판사 협업 여지 보존

### 부정적
- 일부 사내 교재·기업 교육 자료 활용이 "비영리" 해석에 따라 모호 → 별도 문의 처리
