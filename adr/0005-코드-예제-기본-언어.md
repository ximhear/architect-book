# 0005. 코드 예제 기본 언어 — Spring Boot (Kotlin) 와 Go

- **Date**: 2026-05-08
- **Status**: Accepted
- **Deciders**: 저자

## Decision

코드 예제는 다음 두 언어를 기본으로 한다.

- **Spring Boot (Kotlin)** — 도메인 로직, 트랜잭션, 결제·정산 같은 무거운 비즈니스
- **Go** — API Gateway, BFF, 워커, 사이드카, k8s 도구 등 인프라성 / 경량 서비스

다음 보조 언어를 영역별로 추가 사용한다.

- **TypeScript (Next.js / Node.js)** — 프론트엔드 4장, BFF 일부
- **Python (FastAPI)** — 데이터·AI 5장, 일부 ML 서빙
- **SQL** — 데이터베이스 절 전반

## Context

책의 케이스(원픽)는 직매입의 무거운 도메인 + 입점/라이브의 가벼운 인프라 서비스를 모두 가진다.
국내 백엔드 채용 시장에서도 Spring 과 Go 가 양대축이다.

Java 가 아닌 **Kotlin** 을 택한 이유:
- Spring Boot 3.x 의 공식 문서가 Java/Kotlin 병기 표준
- 데이터 클래스·null safety 가 도메인 모델 표현에 유리
- Java 개발자도 큰 학습 비용 없이 읽을 수 있음

## Considered Alternatives

- **Java + Spring Boot**: 가장 보수적. Kotlin 의 표현력 손해.
- **Java + Go**: 시장에는 가장 흔하나 Kotlin 의 도메인 표현 이점 포기.
- **Spring 단일**: 인프라성 서비스의 특징을 잘 못 보여줌.

## Consequences

### 긍정적
- 무거운 도메인 vs 가벼운 인프라의 트레이드오프를 자연스럽게 보여줌
- 국내 채용 시장과 일치 → 독자가 학습 후 즉시 적용 가능

### 부정적
- 두 언어를 모두 읽을 수 있어야 함 (단, 깊이 이해는 한쪽만 해도 OK 라는 가이드 제공)
- 코드 예제 유지보수 비용 2배
