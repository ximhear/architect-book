## 베타 6 분야

### 보안 (공공/에너지 ISMS-P 심사원)
- **분산에너지 활성화 특별법 (2024.6.14 법률 19470호)** — 특화지역/통합발전소/직거래 3 경로 미분리. **세종이 특화지역인지가 케이스 정체성 좌우**
- "정식 분산자원 사업자 라이선스" → 정확한 용어 "소규모전력중개사업자 등록"
- 전기 사용량 "PII 와 같은 등급" = 등급 낮추는 실수. 3분류 필요 (민감/준민감/일반)
- 「에너지이용합리화법」 을 "DR 사업 근거" 로 잘못 인용 — 정답: 전기사업법 + KPX 운영규칙
- **CSAP / KCMVP / PIA 책에 0회** — 공공 사업 책에서 치명적
- IoT 보안 6줄 — EST/SCEP / OTA dual partition / SBOM 전부 누락
- 「개인정보 보호법」 제23조 민감정보 / 제37조의2 자동화 결정 거부권 누락

### 인프라/SRE (NCP/IoT 운영 5년+)
- **"NCP 단일 + 99.99% 안전 알람 + Grafana Cloud" 동시 성립 불가** — SENS SPOF, Grafana Cloud 한국 리전 없음 (데이터 주권 위반)
- **인프라 3명 = 5 역할 = 1.67 FTE 부족**
- **챕터 간 결정 충돌** — 케이스 11.1 "NCP 단일" vs 8장 3절 "NCP+AWS 보조" 표기 + Vercel 3가지 버전
- **5분 SLA 도달률 분해 부재** — FCM 95-97% × SMS 98-99% × 자동전화 80-90% 누적이 99.99% 미달
- NCP 매니지드 격차 — TimescaleDB / ClickHouse / Vault 매니지드 없음

### 백엔드 (Spring + Go + IoT 8년)
- TimescaleDB hypertable 운영 함정 (chunk·압축·CAGG·retention 충돌)
- IoT ingester 처리량 모순 — 본문 "300/3,000 RPS" vs 표 "수만 TPS"
- DR Auto-scale 비현실 — NKS 콜드 3~5분, "1분 1→8" 은 폭주 후
- 매칭 정산 + 세무 4단 흐름 누락 — 25명 조직은 외부 SaaS 통합 강제
- 시니어 인증 보안 비용 — PASS 1회 + Refresh 60일 무검증 = 부재 추론 60일 노출
- 대인 매칭 신뢰 4계층 (신원/평점/분쟁 SLA/에스크로) 누락
- **같은 저자 일관성 신호**: 1권 베타가 짚은 관측성/Saga 보상/refresh reuse 가 2권에서 영역만 바뀌어 재발

### 프론트 (시니어/공공 8년)
- **단순 모드 default ON 기준 누락** — 65세 자동 = 차별 / 본인 토글 = 가장 필요한 사람이 못 찾음
- Web Speech vs Native SFSpeechRecognizer 구분 누락, 시니어 한국어 WER 1.5~2배
- **「지능정보화 기본법」 제46조 + KWCAG 2.2 + 키오스크 접근성 (2023 시행령 개정)** — 공공 위탁 계약 조건
- 옥외 단말 5층 운영 누락 (HW IP65 / OS·MDM / Kiosk / 오프라인) — "Next.js Kiosk 모드" 는 SW 1층
- 첫 화면 250KB = Pretendard 80-120 + Recharts 60-80 → 그래프 화면 시작 200KB
- **DR 5분 응답 = 1인당 6초 결정** → 시니어 응답률 30~50%
- 8장 결정표에 모바일만 한 줄, 채널 6개 중 5개 누락

### 데이터/ML (에너지 시계열 5년+)
- **DR 예측 Prophet 단위 오류** — 가구별 MAPE 40~80% 무력. 동·면 집계가 운영 현실. 그대로 출간 시 1분기 안에 모델 폐기
- TimescaleDB 인스턴스 분리 모호 — 케이스 11.2 / 5장 / 8장 결정표 다 다르게 읽힘. WAL/VACUUM 경합 사고 위험
- **취약계층 FP/FN 비대칭 누락** — FN 1 = 사망/사업중단, FP 100 = 사회복지사 신뢰 손실
- HyperCLOVA X 단정 — ZRR 모델별 정책 차이 / 가격 / 한국어 정확도 단순화
- AI Gateway fallback이 GPT 로 PII 흘리는 함정
- k<5 셀 재식별 위험 자동 차단 룰 없음
- SHAP → 사회복지사 콘솔 자연어 변환 누락

### 타깃독자 (1권 읽은 8년차 → 아키텍트)
- **1권 안 읽은 사람이 2권만으로 이해 가능 — 약함**. 0장 "본 책만 완결" 선언과 본문 어긋남
- **19개 결정 비교표 = 표지급 자산** (단 1권 결정 압축 거칠어 1권 미독자는 절반만 이해)
- 30~40명 커머스 스타트업 리드에 70% 적용 — 1장 1.2 "흔한 함정 4가지" 박스가 단독으로 1만 원 가치
- **1+2권 묶음 강력 권장, 2권만은 비권장**
- **출간 전 반드시 손봐야 할 한 가지**: 0장 정직성 결판 — (a) 1권 사고 골격 부록 (b) "1권 먼저" 솔직 (c) 어정쩡함 유지 — 셋 중 결판
