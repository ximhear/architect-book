# 피드백 — 1권 읽은 시니어 백엔드 → 아키텍트 전환자 (가상 2권 베타)

날짜: 2026-05-18

> 입장: 8년차 시니어 백엔드 (Spring/Kotlin, 일부 Go). 30~40명 커머스 스타트업 백엔드 리드.
> **1권 (원픽) 을 이미 정독**. 1차 베타 때 "한 권에 한국 시장 무대가 일관되게 깔린 게 결정적" 이라 평가했음.
> 2권 (동네에너지) 베타로 4개 파일을 두 시간에 읽음. 비교 시각이 핵심 — 두 권을 같이 살 가치가 있는가, 1권만으로 충분한가.

## 1. 두 책의 본질적 차이 — 1권 독자가 2권에서 새로 배우는가 (A) ← **가장 중요**

| 영역 | 1권에서 이미 배운 것 | 2권의 새로움 | 진짜 학습 가치 |
|------|------------------|------------|--------------|
| **NFR 우선순위 재배치** | 7가지 NFR · 정량화 · 트레이드오프 | "같은 7가지가 다른 우선순위" — 가용성 ★★★ → ★★★★, 운영성 ★★ → ★★★★ | **있음**. 단 1권의 NFR 표 한 줄 추가 다시 보는 수준 — 1권 독자에겐 "재확인" 에 가까움 |
| **아키텍처 스타일 결정** | 모듈러 모놀리스 + 점진 추출 (4단계) | "처음부터 IoT 만 분리 — 작업 부하 기준" | **결정적**. 도메인 vs 부하 분리 기준의 대비는 1권에 없음. 1권은 도메인 분리 일색이었던 게 1차 베타에서도 지적됐던 약점. **이 한 가지만으로도 1권 독자가 2권을 살 이유** |
| **클라우드 결정** | AWS 메인 + NCP 보조 (DR) | NCP 단일 + 의식적 락인 인지 | **있음**. 1권은 "왜 NCP 보조" 였고, 2권은 "왜 NCP 단일" — 같은 결정이 정반대 방향에서 내려진다는 시연이 강력 |
| **DB 다양성** | Aurora/PG/Mongo/Redis/Dynamo/OpenSearch (6종) | PostgreSQL + TimescaleDB + Redis + ClickHouse (사실상 4종, 코어는 1종) | **있음**. "DB 다양성을 통제하는 결정" 은 1권 독자가 가장 후회한다고 한 영역과 매칭 |
| **공공 협력** | PG · 본인인증 위탁만 | 한전 · KPX · 세종시 · 복지부 → ADR 에 "공공 위탁 영향" 한 줄 추가 | **결정적**. 1권에 전혀 없음. 공공·금융 도메인 시니어에겐 2권이 본편 |
| **시계열 IoT** | 트랜잭션 일색 | 일 2,700만 record, TimescaleDB hypertable, continuous aggregate | **결정적**. 1권 5장 데이터 챕터의 약점 (트랜잭션 OLTP 일색) 을 2권이 보완. 단 본 베타 범위에선 5장 본문 미확인 — 깊이가 1권 만큼 나오는지 검증 필요 |
| **작은 조직 (25명) 의 결정** | 220명 기준 | 1/10 조직에서 220명 결정이 어떻게 무너지는가 | **결정적**. 1권의 결정 표를 그대로 가져오면 무너지는 4가지 (8장 5.x 박스) 가 가장 강력한 1권 보완 |
| **시니어 / 접근성 / 취약계층** | 거의 없음 | UX 강제, Access 토큰 30분, PASS 우선, 5분 안전 알람 | **있음**. 1권에 약한 영역. 단 본 베타 범위에선 4장 / 6장 본문 미확인 — 표 한 줄 이상의 깊이가 있는지 검증 필요 |

### 결론 — 1권 독자가 2권을 살 가치

**있다. 단 "1권의 결정 표가 케이스에 따라 어떻게 갈라지는가" 의 시연집으로서 가치**. 새로운 사고법은 거의 없음 — 1권의 사고 골격을 그대로 적용한 두 번째 무대. 이 정체성을 0장이 더 강하게 내세워야 함 (현재는 "같은 골격 다른 무대" 라고 한 줄로 끝남 — 약함).

## 2. 1권 안 읽은 사람이 2권만으로도 이해 가능한가 (B)

| 위치 | 발견 | 1권 미독자 시점 |
|------|------|--------------|
| 0장 1절 "1권을 읽지 않아도 본 책만으로 완결" | 선언만 있고 보장 장치가 약함. 1권 1장의 NFR 7가지 · ADR 형식 · C4 가 2권 1장에서 "그대로다" 로 처리됨 (1장 들어가며 "사고 골격은 그대로다") | **위반**. 1권 미독자는 1장에서 NFR · BC · ADR · C4 에 대한 설명 없이 "우선순위만 다르다" 는 표를 만남. 책 한 권으로 완결 안 됨 |
| 1장 1.1 "1권 220명 대비" 표 | 1권 220명 조직의 시간 분배가 비교 기준인데, 그 분배가 어디서 왔는지 본문에 없음 | 1권 미독자는 "1권 220명 의 30% 코드" 가 어디서 나온 숫자인지 모름 |
| 1장 3.1 "1권 결정 매트릭스 다시 보기" | 5문항 자체를 다시 인용하지 않고 표 헤더만 가져옴 | 1권 미독자는 매트릭스 자체를 모르는데 답만 채워진 표를 봄 |
| 8장 3절 19개 결정 비교표 | "1권 결정 / 2권 결정 / 차이의 이유" 3열 — 1권 결정을 한 줄로 압축해 인용 | **여기는 잘 됨**. 1권 미독자도 "1권은 이랬다는데" 정도는 잡힘 |
| 8장 9절 "두 책의 차이" | "한 권만 읽어도 좋다" 로 끝맺음 — 정직 | 그대로 |

### 결론 — 1권 미독자의 2권 단독 가독성

**약함**. "본 책만으로 완결" 이라는 0장 선언과 실제 본문이 어긋남. 두 가지 길:

1. **권장**: 0장에 "1권을 안 읽은 독자를 위한 부록 — 1권 1장 사고 골격 6쪽 요약" 부록을 둘 것. NFR 7가지 / Bounded Context / ADR / C4 의 한 페이지씩 요약.
2. **대안**: 0장 1절을 솔직하게 "1권을 먼저 권한다. 2권만으로도 읽히지만 사고 골격은 1권에 있다" 로 바꿀 것. 이게 1권 마케팅에도 유리함.

지금은 두 입장 사이에서 어정쩡함.

## 3. 8장 19개 결정 비교표 — 실제 의사결정에 쓸 만한가 (C) ← **2권의 표지급 자산**

| 측면 | 평가 |
|------|------|
| 한 장으로 압축한 가치 | **사진 찍어 책상 앞에 붙일 만함**. 1권 8장 21행 결정 요약표가 1권의 시그니처였듯, 2권의 19행 비교표가 2권의 시그니처 |
| "차이의 이유" 열 | **결정적**. 1권의 결정 요약표는 "근거" 열이 "장 번호" 뿐이었음. 2권은 "분리 기준이 부하 vs 도메인" 같은 한 줄 사유 — 이게 진짜 학습 자료 |
| 19개 중 15개가 다르다는 카운트 | "케이스가 바뀌면 결정이 바뀐다" 의 정량 증거. 좋음. 단 카운트 기준이 "다르거나 강도가 다름" 으로 느슨함 — 진짜 다른 것 vs 강도만 다른 것을 구분하면 더 강력 |

### 실제 의사결정에 쓸 때 막히는 곳

| 행 | 문제 | 제안 |
|----|------|------|
| "API — 내부 단순 / 외부 REST" vs 1권 "외부 REST · 내부 gRPC · BFF GraphQL" | 2권 결정이 "조직 작아 BFF / gRPC 미도입" 한 줄 — 자기 회사 (30명) 가 어디에 있는지 모름. 25명까진 안 쓰고 220명부터는 쓴다는 임계가 안 잡힘 | 한 줄 추가: "임계 — 도메인팀 3개 이상 / 모바일 채널 2개+ 가 동시에 다른 응답 형태 요구할 때" |
| "메시징 — NCP CDSS (Kafka 호환)" | 1권 "Kafka MSK + SQS" 와의 차이가 "단일 클라우드" 한 줄 — 호환성 / 운영 부담 / lock-in 의 트레이드오프가 안 보임 | "CDSS 의 Kafka 호환성 한계 (consumer group rebalancing 등)" 한 줄 또는 ADR 링크 |
| "BFF — 없음" | 1권에서 BFF 가 핵심이었던 만큼 "없음" 결정의 사유 1줄 부족. "Next Server Action 만" 으로 진짜 충분한가가 시니어 독자의 첫 질문 | "Next Server Action 으로 도달 가능한 한계 — 모바일 앱 별도 BFF 시 점" 한 줄 |
| "비용 18~25% (sponsor 일부)" vs 1권 "10~14%" | 1.8배 차이의 이유가 "규모 / sponsor" 한 줄. 시니어 독자는 "공공 sponsor 가 빠지면 30% 까지 가는가" 가 궁금 | sponsor 빠진 가정 시 비율 한 줄 |

### 19개 결정 표의 사용성

- **인쇄해서 회의실에 붙이고 자기 조직과 매핑** 가능한 형태. 1권 8장 표보다 한 단계 진화함
- 단 1권 결정 열의 압축이 거칠어 1권 미독자는 절반쯤만 이해함 (위 2절과 같은 문제)
- 19행을 3구간 (25명·100명·220명) 으로 보여주는 "3열 → 4열" 확장을 8장 끝쯤 따로 두면 책 전체의 적용 폭이 2배가 됨

## 4. 25명 조직 / 공공 협력 / IoT 시계열 — 자기 환경에 적용 가능한가 (D)

| 자기 환경 | 적용 가능성 | 막히는 곳 |
|---------|-----------|---------|
| **30~40명 커머스 스타트업 (내 회사)** | **70%**. 25명 결정이 가장 가까움. NFR 우선순위 재배치 표는 그대로 적용 가능 | 공공 협력 없음 / IoT 없음 — 1·8장 본문의 1/3 이 무관함. 8장 8절 "작은 스타트업 (10명)" 행이 너무 짧음 (1권 8장에서도 같은 지적) |
| **10~15명 SaaS** | **50%**. 모놀리스 + 단일 DB 결정이 그대로 적용 | "작업 부하 분리 (IoT)" 가 자기 도메인에 없으면 분리 사유 자체가 사라짐. 1권보다 더 모놀리스 안에 머무는 결정으로 가야 — 그 안내가 없음 |
| **공공 / 스마트시티 / 에너지 직접 종사자** | **95%**. 이 책의 1차 고객. 1권보다 2권이 본편 | 그대로 — 단 분산에너지 활성화 특별법 / 전기사업법 인용에 시점 / 조문이 빠진 곳 다수 ([P1] 참조) |
| **IoT / 시계열 입문** | **80%**. TimescaleDB + ClickHouse + continuous aggregate 패턴이 한 자리에 | 본 베타 범위 외 (5장 미확인). 5장 본문의 깊이가 보장돼야 |
| **글로벌 SaaS** | **15%**. 한국 단일 / 공공 / 시니어 / 세종페이 — 거의 적용 못 함 | 0장에서 의도적 제외 선언 — 정직 |

### 자기 환경 (30~40명 커머스 스타트업) 입장에서 가장 인상 깊은 한 가지

**1장 1.2 "흔한 함정 — 25명에서 220명 책을 그대로 따라가지 말 것"** 박스. "MSA 80개 / SRE 별도 / 도메인팀 7개 / 자체 관측성 self-host" 4개가 1권 결정을 그대로 가져오면 무너진다는 시연. **1권 베타 때 가장 큰 걱정 (작은 조직이 220명 결정을 모방하는 위험) 이 정면 해소됨**. 이 박스 하나가 30~40명 리드에게 1만 원짜리 가치는 함.

## 5. 너무 추상 / 너무 세부 / 누락 / 사족 (E) ← **본 베타의 핵심**

| 위치 | 어떻게 읽혔는가 | 제안 |
|------|---------------|------|
| **0장 전체** | **약함**. 1권 0장 (책의 사명 / 무대 / 8장 구성) 의 1/3 분량. "1권과의 관계" 가 절반을 차지해 책 자체의 정체성 진술이 빈약 | 0장에 "2권 자체가 무엇인가" 한 절 보강. 현재는 "1권의 또 다른 무대" 로만 정의되고 있어 책 자체의 자존이 약함 |
| **0장 4절 "1권과 같은 것 / 다른 것" 비교표** | **결정적으로 좋음**. 9행 표 한 장으로 두 책의 정체성이 잡힘. **서점 미리보기에 이 표를 넣으면 1권 독자가 즉시 산다** | 그대로 — 단 "1권 학습 적용" 마지막 행 "이 책의 표준" / " 큰 책의 결정이 작은 조직에서 어떻게 다른가의 시연" 의 비대칭이 어색. 양쪽이 정렬되게 |
| **0장 6절 "읽는 순서 표"** | "1권 읽은 독자 → Case → 08" 두 챕터만으로 끝남. 이건 정직하다 못해 책 판매에 손해 — 1권 독자에게 "1장과 0장도 읽어라" 가 더 좋음 | "1권 읽은 독자 → 00 → 04(차이) → Case → 01 → 08" 정도. 0장의 비교표가 살아야 책의 정체성이 잡힘 |
| **케이스 1.1 "5개 축 (대인 영역 강조)"** | **2권의 정체성**. 1권의 "원픽 = 종합 커머스" 와 격이 다른 무대 정의. P2P / 매칭 / 복지 3개 대인 영역이 5개 축의 중심 | 그대로 |
| **케이스 4 "팀 구조 25명"** | **결정적**. 1권 4절의 220명 조직도와 정면 대비. 한 사람이 여러 영역 한다는 한 줄이 1권 독자에게 가장 큰 학습 | 그대로 |
| **케이스 5.1 "법규"** | 8개 법규 나열. 단 **분산에너지 활성화 특별법 / 전기사업법 / 신·재생에너지법 / 에너지이용합리화법** 4개의 조문 / 적용 범위가 한 줄도 없음. "확인 필요" 표시가 한 줄 (P2P) | [P1] — 시점 / 조문 / "확인 필요" 표시 강화. 1권 6장의 개보법 인용 수준은 돼야 |
| **케이스 5.2 "공공 위탁 1건 사고 = 사업 중단"** | **결정적**. 1권에 없던 비즈니스 리스크 정의. 6장 보안 결정의 무게가 1권과 본질적으로 다른 이유 | 그대로 |

### 1권에는 있는데 2권에 빠진 절

- **약어 풀이 박스** (1권 8장 상단). 2권은 시계열·DR·IoT·AMI·KPX 등 1권에 없던 약어가 다수 — 약어 풀이가 0장에도 8장에도 없음 [P2]
- **시즌 대비 체크리스트** (1권 8장 4.3). 2권의 "혹한·혹서·DR 5,000 TPS" 가 1권의 "블프·명절" 과 같은 카테고리인데 같은 체크리스트가 없음
- **3년 비전 트리거 표** (1권 8장 6절). 위 표 8장 6 항목 참조
- **자신의 프로젝트 5행 매핑** (1권 8장 8절). 1권 5행 → 2권 5행이지만 깊이가 얕음

- **1장 들어가며 "본 장은 1권 1장의 골격을 가정"** — 1권 미독자에겐 책 한 권으로 완결 안 됨의 명시적 인정. 양가적

## 6. 가격 대비 가치 — 1권 + 2권 묶음 vs 1권만 (F)

| 시나리오 | 가치 평가 |
|---------|---------|
| **1권만 (3만 원 가정)** | 8년차 시니어 → 아키텍트 전환 1차 입문서로 정답. 한국 시장 무대 + 220명 조직 결정의 표준 |
| **2권만 (3만 원 가정)** | 공공·에너지·IoT 종사자에게는 본편. 그 외에는 1권 미독자 입장에서 사고 골격이 비어 있어 추천 어려움 |
| **1권 + 2권 (5~6만 원 묶음 가정)** | **30~40명 커머스 스타트업 리드 입장에서 매우 권장**. 묶음 가격이 단권의 2배 미만이면 안 살 이유가 없음. 이유: (1) 1권 결정 표 + 2권 19개 비교표 두 장이면 자기 조직 의사결정 90% 커버 (2) 220명 / 25명 의 양 극단을 모두 보면 자기 조직 (중간) 의 위치가 잡힘 (3) 1장 5.2 + 8장 3절 두 표가 두 책을 묶어 한 권으로 만듦 |
| **이미 1권 산 사람 (1만 5천 원 추가)** | **권장**. 단 "1권 결정의 시연집" 임을 명확히 알린 가격이어야 정직. 새로운 사고법은 없음 — 1권 사고법의 두 번째 적용 |
| **2권만 사고 1권 안 살 사람** | 비권장. 위 2절 (1권 미독자) 참조. 2권만으로는 사고 골격이 빈약 |

### 두 책의 묶음 가격 정책 제안

- 묶음 할인 (각 3만 → 묶음 5만) 강하게 — 2권만 사는 사람은 별로 없을 것
- 1권 독자에게 2권 PDF 만 1만 5천 원에 추가 판매 — 2권의 가치가 "1권 결정 표의 두 번째 시연" 임을 직설

## 7. 출간 전 반드시 손봐야 할 한 가지 (G) ← **본 베타의 결론**

> **2권 0장 1절 "1권을 읽지 않아도 본 책만으로 완결된다" 의 정직성**.

현재 상태: 선언만 있고 보장 장치가 없음. 1권 미독자는 1장의 "1권 1장의 골격은 그대로다" 부터 막힘.

세 가지 선택지:

1. **(권장) 0장에 "1권 사고 골격 6쪽 요약" 부록** — NFR 7가지 / Bounded Context / ADR / C4 의 한 페이지씩. 이러면 정직하게 "완결" 이라고 선언 가능.
2. **(차선) 0장 1절을 "1권을 먼저 권한다" 로 솔직하게** — 책 판매에 단기 손해처럼 보이지만 신뢰가 올라가 묶음 판매가 됨.
3. **(현 상태 유지)** — 어정쩡함. 1권 미독자는 2권을 사도 막힘. 1권 독자는 "왜 같은 골격을 또 설명하는가" 의 어색함. 양쪽 모두 만족 못 함.

**이 한 가지가 2권의 정체성 / 1권과의 관계 / 가격 정책 / 마케팅 메시지 모두를 결정함**. 출간 전 반드시 결판내야 함.

다음 차순위 한 가지 (있다면): **8장 19개 결정 비교표를 책의 표지급 자산으로 마케팅** — 1권 8장 3절 21행 결정 요약표가 1권의 시그니처였듯, 2권의 19행 비교표를 책 소개 / 미리보기 / 서점 매대에서 무조건 노출. 이 한 표가 1권 독자의 구매를 결정함.

## 종합 — 한 줄로

> "1권을 읽은 시니어 아키텍트 전환자에게 2권은 **새로운 사고법이 아니라 1권 사고법의 두 번째 무대** 다. 그 정체성을 정직하게 내세우고 (0장 1절 결판) 8장 19개 결정 비교표를 책의 표지급 자산으로 띄우면 — 1권 + 2권 묶음은 30~40명 커머스 스타트업 리드에게 5만 원 가치를 한다. 새 학습은 (1) 작업 부하 vs 도메인 분리 기준 (2) 25명 조직에서 220명 결정의 한계 (3) 공공 협력 ADR 양식 세 가지에 집중되어 있고, 이 세 가지만으로도 1권 독자가 2권을 살 이유는 충분하다."
