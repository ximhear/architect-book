## 본 책의 차별점 (1권 대비)

| 측면 | 1권 — 원픽 | 2권 — 동네에너지 |
|------|-----------|------------------|
| 시장 | 전국 B2C 커머스 | 세종 단일 도시 (39만 명, 활성 5만 가구) |
| 트래픽 특성 | 사용자 트랜잭션 | **IoT 시계열 폭주** (스마트미터 15분 주기) |
| 데이터 핵심 | 주문·결제 | 시계열 + 시민 행동 + 공공 외부 |
| 공공 연계 | PG·간편로그인 | **한전 / 전력거래소 / 세종시 데이터허브 / 복지부** |
| 신뢰 위험 | 결제·사기 | **전기 사용 = 생활 패턴 추론**, 취약계층 식별 |
| 비즈 모델 | 수수료·마진 | 거래 수수료 + 매칭 + **공공 협력 sponsor** |
| 조직 규모 | 220명 | **26명** 스타트업 + 공공 협력 |
| 1권 학습 적용 | 이 책의 표준 | "큰 책의 결정이 작은 조직에서 어떻게 다른가" 의 케이스 |
