# 케이스 스터디 — 동네에너지 (MaeulEnergy)

> 본 책 (2권) 전체를 관통하는 가상의 세종 스마트시티 시민 참여형 에너지 플랫폼.
> 모든 장의 예제·다이어그램·트레이드오프는 이 서비스를 기준으로 한다.
>
> 실존하는 어떤 사업과도 무관하다. 단 세종 스마트시티 5-1 생활권의 공개 자료를 토대로 합성했다.
>
> [ADR-0008](../../adr/0008-케이스-단일-출처-원칙.md) 단일 출처 원칙 — 새 사실은 이 문서를 먼저 갱신 후 챕터에서 인용.

## 한 문장 정의

**동네에너지(MaeulEnergy)** 는 세종 스마트시티 5-1 생활권을 무대로, **시민 참여형 통합 에너지 플랫폼** 을 운영한다.
가정 IoT 모니터링 + 수요반응(DR) 보상 + P2P 잉여 전력 거래 + 에너지 컨설팅·시공사 매칭 + 취약계층 에너지 복지 — 5개 축을 한 시민 앱에 묶었다.
세종시 스마트시티 사업의 일부로 시작 (시민 5만 가구 활성). 운영 3년차, 공공 위탁 + 시리즈 A 마친 비영리 + 영리 혼합 조직.

## 1. 비즈니스 / 도메인

### 1.1 5개 축 (대인 영역 강조)

| 축 | 설명 | 대인 / 공공 요소 | 매출 모델 |
|----|------|---------------|----------|
| 1. **IoT 모니터링** | 가정 스마트미터·태양광·EV·웨어러블 데이터 수집 + 시각화 | 사용자 본인 | 무료 (플랫폼 게이트웨이) |
| 2. **수요반응 (DR) 참여** | 피크 시 시민이 절약 → 한전 / KPX 보상 → 시민에 지역화폐(세종페이) 환급 | 시민 ↔ 한전 | DR 보상의 10~15% 수수료 |
| 3. **P2P 잉여 전력 거래** | 가정 태양광 잉여 → 이웃에 판매 (시범사업) | 시민 ↔ 시민 | 거래 수수료 3% |
| 4. **컨설팅·시공사 매칭** ★ | 에너지 진단사·단열·보일러·태양광 시공사를 시민에 매칭 | 시민 ↔ 진단사 ↔ 시공사 (**핵심 대인 영역**) | 매칭 / 시공 수수료 |
| 5. **취약계층 에너지 복지** | 에너지 빈곤 가정 자동 식별 + 복지부·지자체 연계 | 시민 ↔ 공공 ↔ 사회복지사 | 공공 위탁비 |

### 1.2 비즈니스 KPI (가정)

- **활성 가구**: 5만 (세종시 전체 가구의 약 30%)
- **연 거래액 (P2P + 컨설팅·시공)**: 약 80억 원
- **DR 보상 환급액**: 연 약 12억 원 (시민 ↔ 한전 중개)
- **공공 위탁 + sponsor 수입**: 연 약 15억 원 (취약계층 연계 + 데이터허브 활용료)
- **운영 매출 합계**: 연 약 30~40억 원 (소규모 스타트업 + 비영리 혼합)

## 5. 제약 / 컴플라이언스

### 5.1 법규 (대한민국 — 본 케이스 특수 영역)

> ⚠️ 본 케이스는 2026년 상반기 기준. 에너지 법규는 분기 단위로 변동 — 실 적용 시 최신 조문 확인.

- **전기사업법** — 전력 판매·중개·자가발전 등. **P2P 거래는 현재 시범사업 제도 (분산에너지 활성화 특별법) 안에서만 합법** (확인 필요)
- **분산에너지 활성화 특별법** (2024 시행) — 분산자원 시민 참여 허용
- **신·재생에너지법** — 태양광 설치·보조금
- **에너지이용합리화법** — DR 사업 근거
- **개인정보보호법** — 전기 사용량은 **준 민감정보** (생활 패턴 / 가족 구성 / 부재 추론 가능)
- **전자금융거래법** — DR 보상 환급 + P2P 정산 (소액이라도 적용 검토)
- **사회복지사업법** — 취약계층 데이터 처리 + 정보 공유 동의

### 5.2 비즈니스 제약

- **DR 호출 응답 SLA**: 한전 / KPX 가 정한 응답 시간 내 정확한 절전량 보고 (분 단위 정확도)
- **취약계층 안전 SLA**: 혹한 / 혹서 시 웨어러블 알람을 5분 이내 사회복지사에게 전달
- **P2P 거래 정합성**: 잉여 전력 측정·정산 오차 0건 목표 (한전과의 정산 정합)
- **공공 신뢰**: 단 1건의 데이터 사고도 사업 중단 위험 (공공 위탁 계약 조건)

### 5.3 기술 제약

- **IoT 데이터 손실률**: 0.1% 이하 (DR 보상 / P2P 정산의 정확성)
- **시민 앱 응답**: p95 < 500ms (피크 시), 첫 화면 < 250KB
- **공공 API 호출 한도**: 한전 / KPX / 세종시 데이터허브 각각 일일 호출 한도 — 캐싱·배치 필수
- **데이터 보존**: 시민 전기 사용량 5년 (개보법 시행령) + DR 보상 정산 기록 영구

## 8. 인프라 / 클라우드 정책

> 정책 수준만 명시. 구체 채택은 [11. 기술 스택 상세](#11-기술-스택-상세-가정).

- **NCP 단일 클라우드** — 공공 데이터 연계·정부 사업 가점·시민 데이터 주권. 보조 클라우드 없음 (외부 SaaS 만 클라우드 외부).
- **온프레미스 옵션** — 한전 / 세종시 데이터허브 연동에 일부 폐쇄망 가능성
- **데이터 주권** — 모든 시민 데이터는 NCP 한국 리전. 분석 / AI 학습도 한국 리전 (HyperCLOVA X).
- **장애 격리** — 취약계층 안전 알람 경로는 다중화 (앱 푸시 실패 시 SMS, SMS 실패 시 전화 자동 — 모두 NCP SENS 경유)
- **단일 클라우드 락인 인지** — 멀티클라우드 운영 부담을 25명 조직이 못 짊어진다는 명시적 결정. 락인 회피는 IaC (Terraform) + 도구 추상화 (OpenTelemetry / Helm) 로 부분 완화.

### 10.1 구체 신호 (수치 기준)

- **조직**: 25명 (엔지니어 17 + 사업 운영 8). 1권 220명의 1/10.
- **IoT 입력**: 일 2,700만 record / 월 8억 / 연 100억+
- **DR 호출 폭주**: 순간 5,000 TPS — 분당 8,000 응답 메시지 처리
- **취약계층 안전**: 혹한·혹서 시 일 평균 30건 알람 / 5분 이내 사회복지사 도달률 99.9% 목표
- **공공 API 호출**: 한전 AMI 일 호출 한도 X (협의 가정), KPX 호출 분당 60건 한도 (가정)
- **시민 신뢰 사고**: 단 1건 데이터 유출 = 공공 위탁 중단 — 사실상 회사 위기
- **P2P 거래 정합 오차**: 한전 측 정산과 0.01% 이내 — 분기 1회 reconciliation

| LLM (시민 챗봇) | **HyperCLOVA X** (NCP) — 한국어 특화 + 공공 가점 |
| IAM | NCP Sub Account + 권한 그룹 |
| 감사 로그 | NCP Cloud Activity Tracker |

### 11.2 백엔드

#### 11.2.1 서비스 (작은 조직 — 모놀리스 + 추출)

- **모놀리스**: 단일 Spring Boot (Kotlin) — 회원 / 매칭 / 복지 / P2P 정산
- **IoT ingester** (별도): Go — 초당 수만 record 처리, 단순·빠름·메모리 효율
- **DR 응답 처리기** (별도): Go — 순간 5,000 TPS 폭주 대응
- **알람 처리기** (별도): Go — 다중화 (앱 푸시 → SMS → 전화)

#### 11.2.2 DB

| 도메인 | DB | 비고 |
|--------|----|----|
| 회원 / 매칭 / 정산 | PostgreSQL (NCP Cloud DB) | RLS 활용 (시민·진단사·사회복지사 격리) |
| **시계열 (IoT)** | **TimescaleDB** | PostgreSQL 확장 — DB 1종 통일 + 시계열 hypertable |
| 캐시 / 세션 | Redis | NCP Managed |
| 검색 (진단사·시공사) | PostgreSQL FTS (소규모) | OpenSearch 미도입 |
| 분석 / OLAP | ClickHouse (NCP) | 시계열 집계·DR 분석 |

#### 11.2.3 메시징

- **NCP Cloud Data Streaming Service** (Kafka 호환) — IoT ingest + DR 응답
- SQS 대체로 SaaS 큐 (간단한 알람 / 푸시)

#### 11.2.4 인증 / 토큰

- 자체 회원 + 카카오 / 네이버 / PASS (시니어 고려해 PASS 우선)
- 토큰: Access 30분 (시니어 재로그인 부담 감소) + Refresh 60일
- MFA: 사회복지사·진단사 콘솔만 TOTP. 일반 시민은 PASS 단일 인증.

### 11.5 운영

- SRE 별도 X — 인프라 / 플랫폼 3명이 SRE 역할 겸함
- 도메인팀 = 백엔드팀 (분리 안 됨) 1차 온콜
- IC 풀: 인프라 3명 + 백엔드 시니어 2명 = 총 5명. 야간 / 주말 로테이션
- 회고: 모든 P1 인시던트 5일 이내, 비난 없는 회고
- 비용: 분기 1회 리뷰. IT 비용 매출 18~25% (공공 sponsor 일부 충당)
- **공공 신뢰 모니터링**: 별도 KPI — 시민 신뢰 점수 (분기 설문) + 사고 빈도
