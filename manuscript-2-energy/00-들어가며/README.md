# 0장. 들어가며

> 이 책은 1권의 "축약본" 이 아니라, **같은 사고 골격이 다른 무대에서 어떻게 다르게 적용되는가** 의 케이스다.

## 이 장에서 답하는 질문

- 1권을 안 읽어도 되는가?
- 왜 에너지 / 왜 세종 / 왜 "대인" 영역인가?
- 무엇이 1권과 같고, 무엇이 다른가?
- 누구를 위한 책인가?

## 1. 1권과의 관계

[1권 — 원픽 (전국 종합 커머스)](../../manuscript/00-들어가며/README.md) 을 읽지 않아도 본 책만으로 완결된다.
단, 책 곳곳에서 **"1권은 X 였는데 2권은 Y 다"** 형태의 비교가 등장한다. 비교 자체가 학습 가치다 — 같은 트레이드오프 박스가 다른 결정으로 이어지는 것을 보여준다.

## 2. 왜 에너지 / 왜 세종 / 왜 대인

### 2.1 왜 에너지

스마트시티의 7대 영역 (모빌리티 · 헬스케어 · 교육 · **에너지** · 거버넌스 · 문화 · 일자리) 중 에너지는 다음 이유로 책 한 권의 무대로 적합하다.

- **IoT 시계열의 대표 영역** — 스마트미터·태양광·EV — 가구당 일 96~1,440 record. 1권의 트랜잭션 중심 데이터와 명확히 다른 골격.
- **공공 협력의 깊이** — 한전·전력거래소·지자체·복지부가 사업의 핵심. 1권의 PG·간편로그인 외부 의존과 다른 결의 협력.
- **법규의 변동성** — 분산에너지 특별법 (2024 시행) 이후 시민 참여 가능성이 새로 열림. 빠르게 바뀌는 영역.
- **시민 신뢰의 무게** — 전기 사용량은 생활 패턴 추론이 가능한 준 민감정보. 1권의 결제 정보보다 더 미묘한 윤리적 결정.

### 2.2 왜 세종

세종시는 **국내 대표 스마트시티 (5-1 생활권 국가 시범도시)** 다. 인구 39만, 활성 가구 약 17만 — 한 도시 안에서 5만 가구를 활성화시키는 시나리오가 현실적.

지자체 + 행정수도 + 시범도시 결합으로 공공 협력 + 시민 참여 + 정부 사업 가점의 무대가 자연스럽다.

### 2.3 왜 "대인"

에너지 사업이라고 하면 보통 **B2C 검침·고지** 또는 **B2B 산업 에너지** 를 떠올린다. 본 책의 "대인 영역" 강조는:

- 시민 ↔ 시민 (P2P 잉여 전력 거래)
- 시민 ↔ 진단사 / 시공사 (컨설팅·시공 매칭) — **가장 핵심 대인 영역**
- 시민 ↔ 사회복지사 (취약계층 안전)

기술이 아니라 사람과 사람을 잇는 영역이라는 점이 본 책의 정체성.

## 4. 1권과 다른 것 — 한눈에

| 측면 | 1권 — 원픽 | 2권 — 동네에너지 |
|------|-----------|------------------|
| 시장 | 전국 B2C | 세종 단일 도시 |
| 사용자 | 월 1,000만 MAU | 활성 5만 가구 |
| 조직 | 220명 | **25명** (1/10) |
| 데이터 중심 | 트랜잭션 | **IoT 시계열** (일 2,700만 record) |
| 가장 큰 외부 | PG / 간편로그인 | **한전 / KPX / 세종시 데이터허브 / 복지부** |
| 핵심 SLA | 결제 99.99% | **취약계층 안전 알람 5분 이내** + IoT 손실률 0.1% 이하 |
| 핵심 법규 | 개보법 / 전금법 / ISMS-P | + **전기사업법 / 분산에너지 특별법 / 에너지법** |
| 비즈 모델 | 수수료·마진 | 거래 수수료 + 공공 위탁 sponsor |
| 1권 학습 적용 | 이 책의 표준 | "큰 책의 결정이 작은 조직에서 어떻게 다른가" 의 시연 |

## 5. 누구를 위한 책인가

- **1권을 읽은 독자** — 같은 사고 틀이 작은 조직 / 공공 협력 / 시계열에서 어떻게 다르게 적용되는지 보고 싶은 사람
- **공공 / 스마트시티 / 에너지 사업 참여자** — 시민 참여 플랫폼의 아키텍처 결정
- **시계열 / IoT 백엔드 입문자** — 트랜잭션 중심에서 시계열로 시야를 넓히려는 사람
- **작은 조직 (10~30명) 의 리드** — 220명 책의 결정을 그대로 가져오면 무너지는 이유

## 7. 이 책이 의도적으로 다루지 않는 것

- 자체 스마트미터 H/W 제조
- 발전사 / 송배전 운영 영역
- 한전 / 전력거래소 자체 시스템의 내부 아키텍처
- 자체 데이터센터 운영 — 클라우드 + 일부 공공 폐쇄망 연계
- 글로벌 진출 — 세종 단일

위 항목은 본 케이스의 의도적 제외다. 다른 책 / 다른 사업의 영역.
