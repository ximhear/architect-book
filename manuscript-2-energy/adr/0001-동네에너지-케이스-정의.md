# 0001. 케이스 — 동네에너지 (MaeulEnergy)

- **Date**: 2026-05-18
- **Status**: Accepted
- **Deciders**: 저자
- **Scope**: 본 결정은 2권 (`manuscript-2-energy/`) 에만 적용. 1권 (원픽) 과 무관.

## Context

2권의 무대를 정의해야 함. 1권은 전국 종합 커머스 (월 1,000만 MAU, 220명) 였고,
대조를 위해 2권은 의도적으로 다른 무대를 골라야 한다 — 도시 단위 / 작은 조직 / 공공 협력 / IoT·시계열 / 대인 서비스.

## Decision

2권 케이스로 **"동네에너지 (MaeulEnergy)"** 를 정의 — 세종 스마트시티 5-1 생활권의 시민 참여형 통합 에너지 플랫폼.

상세는 [`manuscript-2-energy/case-study/README.md`](../case-study/README.md).

핵심 차별점:
- 세종 단일 도시 (활성 5만 가구)
- 5개 축: IoT 모니터링 / DR 참여 / P2P 거래 / 컨설팅·시공사 매칭 (★ 대인) / 취약계층 복지
- 조직 26명 (1권의 약 1/8) — 베타 검토 후 인프라 3→4, CTO 1 추가
- 일 2,700만 IoT record (시계열 특화)
- 공공 협력 (한전 / KPX / 세종시 데이터허브 / 복지부)

## Considered Alternatives

- **세종 모빌리티 (자율주행·DRT)** — 모빌리티 중심이라 대인 영역 좁음
- **시민 거버넌스 매칭** — 공공 깊지만 8개 영역 채우기 부족
- **P2P 도구 렌탈** — 1권 커머스와 유사도 높아 차별성 약함
- **시니어 돌봄 단독** — 범위 좁아 8영역 부족

## Consequences

### 긍정적
- 1권과 명확한 대비 — 큰 조직 / 큰 트래픽 / 일반 시장 ↔ 작은 조직 / IoT 시계열 / 공공 협력
- 세종 스마트시티 + 분산에너지 특별법 시행 시점과 부합 (현실성)
- 8개 영역 모두 풍부 (특히 5장 데이터, 6장 공공 법규, 7장 작은 조직 운영)

### 부정적
- 에너지 / 전력 법규는 분기 단위로 변동 — 시점 면책 + "확인 필요" 빈도 높음
- 한전 / KPX API 의 실 운영 디테일은 비공개 영역이 많아 가공 비율 높음

### 중립
- 두 책의 케이스 모두 가상이므로 책 자체의 콘텐츠 일관성은 두 책 ADR-0008 (단일 출처) 로 각자 유지
